A complete console-based Blackjack game in Python featuring all major Blackjack rules and mechanics:

- Standard 52-card deck
- Betting system with starting balance
- Multiple rounds play
- Player actions: Hit, Stand, Double Down, Split (multiple splits supported)
- Insurance option when dealer shows an Ace
- Blackjack pays 3:2
- Dealer stands on soft 17
- Correct handling of Aces and busts
- Pushes (ties) handled properly
- Clear text-based user interface
